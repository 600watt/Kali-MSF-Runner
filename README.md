# Kali-MSF-Runner

Termux içinde kurulu olan Kali NetHunter (nh) üzerinden, tek komutla Metasploit Framework'ü başlatan pratik bir araçtır.

## Gereksinimler
- Termux
- Kali NetHunter (Termux'ta 'nh' komutu çalışıyor olmalı)

## Kurulum ve Kullanım
```bash
git clone https://github.com/600watt/Kali-MSF-Runner.git
cd Kali-MSF-Runner
bash run.sh
```

**Not:** Bu araç eğitim amaçlıdır.
